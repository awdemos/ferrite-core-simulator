Physics Explanation

Click on a core to perform the selected operation.

Read: Destructive read - the bit value is returned but cleared to 0.

Write 1: Apply coincident current to flip core to 1.

Write 0: Apply inhibit current to prevent flip, keeping core at 0.

Ferrite core memory was used from the 1950s through the 1970s. Each tiny toroidal core stores one bit via clockwise or counter-clockwise magnetization.
